# 7. Secret Code Verifier

### 🇹🇷 Türkçe
**Program nedir?** Ad ve soyaddan gizli kod üretip doğrulayan bir kimlik doğrulama programıdır.

**Ne işe yarar?** Ad-soyad bilgilerinden dilimleme (slicing) ile gizli kod oluşturur ve kullanıcıdan girmesini ister.

**Bu programla ne yapabilirsin?**
- Ad ve soyad uzunluklarını görebilirsin
- Kişiselleştirilmiş gizli kod alabilirsin
- Kodu doğru girerek giriş doğrulaması yapabilirsin

### 🇬🇧 English
**What is it?** A code generator and verifier program based on your name and surname.

**What does it do?** It creates a secret code from name/surname using string slicing and asks you to enter it back.

**What can you do with it?**
- See the length of your first and last name
- Get a personalized secret code
- Verify your identity by entering the correct code
