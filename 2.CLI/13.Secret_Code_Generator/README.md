# 13. Secret Code Generator

### 🇹🇷 Türkçe
**Program nedir?** `capitalize`, `upper`, `lower` yöntemlerini ve gizli kod üretimini gösteren eğitim programıdır.

**Ne işe yarar?** İsim, soyisim, şehir ve doğum yılından gizli kod üretir; 3 haklı doğrulama oyunu sunar.

**Bu programla ne yapabilirsin?**
- Bilgilerinizi farklı formatlarda yazdırabilirsiniz (büyük/küçük/capitalize)
- Kişiselleştirilmiş gizli kod alabilirsiniz
- 3 hakla kodu doğru girerek doğrulama yapabilirsiniz

### 🇬🇧 English
**What is it?** A training program demonstrating `capitalize`, `upper`, `lower` and secret code generation.

**What does it do?** It builds a secret code from name, surname, city and birth year and verifies it with 3 attempts.

**What can you do with it?**
- Print your info in different formats (upper/lower/capitalize)
- Get a personalized secret code
- Verify the code with 3 allowed attempts
