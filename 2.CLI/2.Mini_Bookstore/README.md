# 2. Mini Bookstore

### 🇹🇷 Türkçe
**Program nedir?** Basit bir sınıf (class) tabanlı mini kitap vitrinidir.

**Ne işe yarar?** `Kitap` sınıfından nesneler oluşturarak kitap adı, sayfa sayısı ve yazar bilgilerini ekrana yazdırır.

**Bu programla ne yapabilirsin?**
- OOP temellerini (sınıf, nesne, `__init__`) görebilirsin
- Kitap bilgilerini düzenli biçimde ekrana yazdırabilirsin
- Yeni kitap ekleyerek örneği genişletebilirsin

### 🇬🇧 English
**What is it?** A simple class-based mini bookstore showcase.

**What does it do?** It creates objects from a `Book` class and prints the book title, page count and author.

**What can you do with it?**
- See OOP basics (class, object, `__init__`)
- Print book details in a structured way
- Extend the example by adding more books
