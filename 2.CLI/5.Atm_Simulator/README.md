# 5. ATM Simulator

### 🇹🇷 Türkçe
**Program nedir?** Menü tabanlı basit bir ATM simülasyonudur.

**Ne işe yarar?** Bakiye sorgulama, para yatırma ve para çekme işlemlerini simüle eder.

**Bu programla ne yapabilirsin?**
- Bakiye sorgulayabilirsin
- TL olarak para yatırabilirsin (min. 100 TL)
- Bakiyene göre para çekebilirsin
- Geçersiz girişlerde hata mesajı alırsın

### 🇬🇧 English
**What is it?** A simple menu-based ATM simulator.

**What does it do?** It simulates balance inquiry, depositing and withdrawing money.

**What can you do with it?**
- Check your balance
- Deposit money in TL (min. 100 TL)
- Withdraw money up to your balance
- Get error messages on invalid input
