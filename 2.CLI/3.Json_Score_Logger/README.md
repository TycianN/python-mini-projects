# 3. JSON Score Logger

### 🇹🇷 Türkçe
**Program nedir?** Oyuncu skorlarını JSON dosyasına kaydeden basit bir kayıt aracıdır.

**Ne işe yarar?** İsim–skor çiftlerini toplar ve `oyuncu_skorlari.json` dosyasına yazar.

**Bu programla ne yapabilirsin?**
- Sonsuz döngüyle birden fazla oyuncu skoru girebilirsin (`çıkış` yazarak bitirirsin)
- Skorları JSON formatında kalıcı olarak kaydedebilirsin
- Varsa aynı isimli dosyayı silip yeniden oluşturabilirsin

### 🇬🇧 English
**What is it?** A simple logger that saves player scores to a JSON file.

**What does it do?** It collects name–score pairs and writes them to `oyuncu_skorlari.json`.

**What can you do with it?**
- Enter multiple player scores in a loop (type `çıkış` to finish)
- Persist scores in JSON format
- Delete and recreate an existing score file if needed
