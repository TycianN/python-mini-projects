# 6. Credential Generator

### 🇹🇷 Türkçe
**Program nedir?** Kişisel bilgilerden önerilen şifre ve kullanıcı adı üreten kimlik oluşturucudur.

**Ne işe yarar?** Ad, soyad, şehir ve doğum yılı alarak metin manipülasyonlarıyla güvenli şifre önerisi yapar.

**Bu programla ne yapabilirsin?**
- Ad/soyad bilgilerini farklı formatlarda yazdırabilirsin (büyük, küçük, capitalize)
- Ad-soyad ve doğum yılından türetilmiş şifre önerisi alabilirsin
- Kullanıcı adı önerisi oluşturabilirsin

### 🇬🇧 English
**What is it?** A credential generator that creates suggested passwords and usernames from personal info.

**What does it do?** It takes name, surname, city and birth year, then uses string manipulation to suggest a strong password.

**What can you do with it?**
- Print name/surname in different formats (upper, lower, capitalize)
- Get a password suggestion derived from name and birth year
- Generate a username suggestion
